# 🏠 Gary 个人主页

基于 **React 19** + **Vite 8** 构建的个人主页。

## ✨ 功能

- 🎨 tsParticles 粒子背景
- 🌓 明暗主题切换
- 📝 歌词打字机效果
- 📊 GitHub 贡献热力图
- 📱 响应式设计
- 🖱️ 滚动吸附 + Tab 自动高亮

## 🚀 快速开始

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
npm run preview  # 预览
```

## 🧩 技术栈

React 19 · Vite 8 · tsParticles · react-github-calendar · react-icons

## 📁 项目结构

```
src/
├── components/   # 通用组件
├── pages/        # 页面组件
├── hooks/        # 自定义 Hook
├── contexts/     # Context
├── data/         # 静态数据
└── styles/       # 样式
```
